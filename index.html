¿Cómo usar Colorfly Studio? 🎨

Domina el generador de paletas interactivo con esta guía rápida.

Generar Paletas

Haz clic en Generar Paleta (o presiona la Barra Espaciadora) para obtener combinaciones aleatorias al instante.

Bloquear Colores

Usa el candado 🔒 en cada color para congelarlo. Al generar una nueva paleta, los colores bloqueados no cambiarán.

Copiar al Portapapeles

Haz clic sobre el código de color (HEX o HSL) de cualquier tarjeta para copiarlo al instante. Verás una notificación Toast de confirmación.

Formatos y Tamaño

Elige mostrar la paleta con 6, 8 o 9 colores y alterna el formato entre HEX y HSL para ver y copiar los valores fácilmente.
